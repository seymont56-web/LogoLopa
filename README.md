# LogoLopa

**LogoLopa** — веб-сервис с развивающими играми для учеников и панелью управления для учителя. Учитель может создавать учеников и настраивать доступ к отдельным играм, а ученик после входа видит только разрешённые ему задания.

## Возможности

- авторизация пользователей по ролям: `teacher` и `student`;
- отдельная панель учителя;
- создание учеников с временным паролем;
- настройка доступа ученика к каждой игре;
- личный кабинет ученика со списком доступных игр;
- запуск игр внутри модального окна через `iframe`;
- смена пароля учеником в профиле;
- защита форм с помощью CSRF-токена;
- хранение паролей в виде хеша.

## Технологии

- **PHP**
- **MySQL / MariaDB**
- **HTML**
- **CSS**
- **JavaScript**
- **phpMyAdmin** для импорта дампа базы данных

## База данных

В проекте используется база данных `logop_games`. Основные таблицы:

- `users` — пользователи сервиса: учителя и ученики;
- `games` — список игр, их коды, названия и пути к HTML-файлам;
- `student_game_access` — связь учеников с играми и признак доступности игры.

Внешние ключи в таблице `student_game_access` связывают доступы с таблицами `users` и `games`, поэтому при удалении ученика связанные настройки доступа удаляются автоматически.

## Установка и запуск

### 1. Склонируйте репозиторий

```bash
git clone https://github.com/seymont56-web/LogoLopa.git
```

### 2. Переместите проект на локальный сервер

Поместите папку проекта в директорию веб-сервера, например:

```text
htdocs/Веб-сервис/logo
```

Для XAMPP это может быть:

```text
C:/xampp/htdocs/Веб-сервис/logo
```

### 3. Создайте базу данных

Откройте phpMyAdmin и создайте базу данных:

```sql
CREATE DATABASE logop_games CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;
```

Затем импортируйте файл:

```text
logop_games.sql
```

### 4. Настройте подключение к базе данных

Откройте файл:

```text
inc/config.php
```

Проверьте параметры подключения:

```php
const DB_HOST = '127.0.0.1';
const DB_PORT = 3307;
const DB_NAME = 'logop_games';
const DB_USER = 'root';
const DB_PASS = '';
```

Если у вас MySQL работает на стандартном порту, замените порт на `3306`:

```php
const DB_PORT = 3306;
```

### 5. Создайте учителя

Если учитель ещё не создан через дамп базы данных, откройте в браузере:

```text
http://localhost/Веб-сервис/logo/create_teacher.php
```

После успешного создания учителя файл `create_teacher.php` нужно удалить, чтобы никто не смог повторно создать администратора.

### 6. Откройте сервис

Перейдите по адресу:

```text
http://localhost/Веб-сервис/logo/
```

## Данные для входа

Если используется стандартный дамп базы данных, в системе есть пользователь-учитель:

```text
Логин: teacher
Пароль: 12345
```

> После первого входа рекомендуется заменить пароль.

## Роли пользователей

### Учитель

Учитель может:

- входить в панель управления;
- создавать новых учеников;
- задавать ученику логин и временный пароль;
- открывать или закрывать доступ к отдельным играм;
- просматривать список учеников.

### Ученик

Ученик может:

- входить в личный кабинет;
- видеть список доступных ему игр;
- запускать игры в окне на странице;
- менять пароль в профиле.

## Как добавить новую игру

1. Создайте папку новой игры в директории `games`, например:

```text
games/game6/
```

2. Добавьте в неё файл `index.html` и необходимые файлы игры.

3. Добавьте запись в таблицу `games`:

```sql
INSERT INTO games (code, title, path)
VALUES ('game6', 'Игра6', '/Веб-сервис/logo/games/game6/index.html');
```

4. Для существующих учеников настройте доступ к новой игре в панели учителя.

## Безопасность

В проекте уже используются базовые меры защиты:

- пароли сохраняются через `password_hash`;
- вход проверяется через `password_verify`;
- формы защищены CSRF-токеном;
- вывод пользовательских данных экранируется через `htmlspecialchars`;
- доступ к страницам ограничивается по роли пользователя.

Рекомендации перед публикацией проекта:

- удалить `create_teacher.php` после создания учителя;
- изменить стандартный пароль учителя;
- не хранить реальные пароли в открытом виде;
- вынести настройки подключения к базе данных в отдельный закрытый конфигурационный файл;
- использовать HTTPS при размещении на сервере.

## Возможные проблемы

### Ошибка подключения к базе данных

Проверьте значения в `inc/config.php`: хост, порт, имя базы, пользователя и пароль.

### После входа появляется ошибка 403

Пользователь пытается открыть страницу, которая не соответствует его роли. Например, ученик не может открыть панель учителя.

### Игра не открывается

Проверьте путь к игре в таблице `games`. Он должен вести к существующему файлу `index.html`.
